# Short links (optional): development.raicorp.in, recruitment.raicorp.in

Asli website ek hi hai: `www.raicorp.in` (development) aur `www.raicorp.in/recruitment/` (recruitment).
Ye do chhote folders sirf short link dete hain, taki visiting card / ads pe `recruitment.raicorp.in` likh sako.
Abhi zaroorat nahi — baad me chahiye to:

1. GitHub pe naya repo (jaise `raicorp-recruitment-link`), `recruitment/` folder ki files root me (CNAME bhi).
2. Settings → Pages → Branch main / root → Custom domain `recruitment.raicorp.in` → Enforce HTTPS.
3. GoDaddy DNS: `CNAME` → Name `recruitment` → Value `<github-username>.github.io`
`development/` ke liye bhi yahi, domain `development.raicorp.in`.
